title: "Summary Table"
---

Turn on **Show Summary Table** to list the groups as a table instead of plotting them. Each row holds a group's value, counts and the limits at its denominator, with the flagged patterns when outlier highlighting is on. The columns follow the tooltip and line settings: hiding a line or a count removes its column, and the tooltip labels name the columns.

Rows can be selected like points, and the table supports cross-highlighting with other visuals. The **Indicator (MISC)** field takes precedence, so the multi-indicator chart is shown whenever indicators are supplied.
